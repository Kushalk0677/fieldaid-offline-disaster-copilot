# Demo Checklist

## Before Recording
- Start Ollama and confirm `gemma4:e4b` is available.
- Start FieldAid at `http://127.0.0.1:8000/`.
- Confirm `models/fieldaid-medic-image-classifier-final/best.pt` exists.
- Prepare one shelter scenario, one fire/flood/damage video, and one risky Trust question.
- Open Mission Mode first.

## Record These Proof Points
- Local URL in browser.
- Mission Mode guided flow.
- Gemma action plan with citations and tool trace.
- Local MEDIC classifier output on photo or video frames.
- Video frame aggregation and created incident.
- Trust refusal for unsafe route/structure claim.
- Discord handoff prompt/outbox record.
- Offline Proof page and sync export.

## Final Assets
- Public code repository.
- YouTube video under 3 minutes.
- Kaggle writeup under 1,500 words.
- Cover image in Media Gallery.
- Live demo instructions pointing to local-first setup.
