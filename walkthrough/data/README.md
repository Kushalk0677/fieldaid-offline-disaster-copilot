# `data/`

Local data used by the FieldAid demo.

- `guidance/`: bundled emergency guidance snippets for local RAG citations.
- `web_samples/`: small public/demo media files for quick browser tests.
- `uploads/`: runtime upload destination for user photos, video frames, annotated frames, and clips.
- `fieldaid.sqlite`: local runtime database generated by the app.

Git tracks guidance and sample media. Runtime uploads and the SQLite database are ignored so private demo data does not get published accidentally.
