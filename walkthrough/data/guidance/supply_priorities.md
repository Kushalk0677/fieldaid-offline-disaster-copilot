# Supply Request Priorities
scenario: combined

Supply requests should connect each requested item to a reported need. Potable water, essential medicines, sanitation, blankets, lighting, charging, and safe transport are common first-wave needs.

When quantities are uncertain, state the known population count and request a field estimate. For blocked access routes, pair supply requests with route verification or alternate delivery planning.

Urgent requests should name a handoff point, responsible contact, and any safety constraint that could delay delivery.
