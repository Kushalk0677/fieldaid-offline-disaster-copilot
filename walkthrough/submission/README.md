# `submission/`

Hackathon submission support material.

- `WRITEUP_DRAFT.md`: concise Kaggle writeup draft under the competition word limit.
- `VIDEO_SCRIPT.md`: 3-minute video structure and narration beats.
- `ARCHITECTURE.md`: project architecture and Mermaid diagram.
- `DEMO_CHECKLIST.md`: recording and proof-point checklist.
- `kaggle_writeup_draft.md` and `video_outline.md`: earlier draft artifacts kept for reference.

Use these files to prepare the final Kaggle writeup, YouTube demo, and public repository description.
